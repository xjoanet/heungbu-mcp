# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

This is a small open-source MCP tool. If you find a security issue, please
open a private GitHub issue or contact the maintainer directly.

We take every report seriously and will respond as soon as possible.
Please do **not** open a public issue for security vulnerabilities —
report them privately first.
